常见问题解答

关于火狐浏览器下载、使用及隐私设置的常见疑问。

火狐浏览器是免费的吗？
是的，火狐浏览器是完全免费的，并且开源的。Mozilla 基金会通过“火狐联盟”计划支持其运营，您可以在遵守协议的前提下自由下载和使用。
Firefox 会收集我的浏览数据吗？
默认情况下，Firefox 不会将您的浏览历史记录、密码或个人数据发送给第三方。我们致力于保护您的隐私，并提供多种设置选项供您控制数据共享方式。
如何导入 Chrome 或 Edge 的书签？
安装 Firefox 后，它会自动检测您电脑上安装的其他浏览器，并提示您导入书签、密码和历史记录。您也可以在设置菜单中手动选择“导入数据”。
