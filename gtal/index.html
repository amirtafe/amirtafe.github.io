核心功能与特性

  • ✓
    XMPP 协议支持

    完全兼容 XMPP 标准，可与支持该协议的其他客户端（如 Pidgin、Miranda、Digsby）互通。

  • ✓
    集成 Gmail 邮件通知

  • ✓
    简洁的聊天界面

    专注于即时通讯体验，支持多标签页聊天，资源占用低。

  • ✓
    基于 TLS 的加密

    支持 SSL/TLS 连接，确保通信内容的安全性。

设置项 填写内容 说明

端口 5223 用于 SSL 连接

常见问题 (FAQ)

Google 已关闭 Google Talk 服务。您无法直接使用官方服务器登录。如果您有旧账号，可以尝试使用支持 XMPP 协议的第三方客户端进行连接，但存在服务不稳定的风险。
本站提供的历史版本文件经过整理。由于软件发布时间较早，请确保您的电脑已安装最新的杀毒软件，并在隔离环境中进行安装，以防范潜在的恶意代码。
Google Talk 本身不提供云端备份。聊天记录仅保存在本地电脑中。如果重装系统未备份，记录通常无法恢复。建议使用支持数据备份的第三方客户端。
